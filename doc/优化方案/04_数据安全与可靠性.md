# 数据安全与可靠性

> 设计方案，未实现；基线 dc18deb7eae6267abd8ccc5e7453c05e89ad1644；事实=静态代码证据，目标=拟定验收。
> 本次没有读取实际连接配置、密码、凭据库、用户历史或数据库；只审阅处理这些数据的源码。

## 1. 威胁模型与信任边界

保护对象：连接秘密、AI 服务秘密、业务结果、SQL 字面量、用户草稿、事务正确性和数据库会话身份。
主要风险：误选生产环境、恶意/错误 SQL、Agent 提示注入、WebView 越权、文件损坏、连接中断与数据外发。
数据库服务、SQL 文本、表名/注释、导入文件、HTTP 返回均视为不可信输入。
本地 Agent 进程不因 localhost 就被信任，剪贴板和导出文件也不属于秘密存储。
系统账户被完全控制、数据库管理员越权、恶意签名应用不在客户端单独可解决的边界内。
Keychain 与最小权限是降低攻击面，不是对已完全控制宿主的攻击者作绝对保密承诺。

| 边界 | 现状证据 | 推荐控制 |
| --- | --- | --- |
| WebView → Rust | [命令注册](../../src-tauri/src/lib.rs#L1060-L1098) | 窗口身份、能力、revision、句柄所有权与后端审批 |
| Rust → DB | [连接 options](../../src-tauri/src/lib.rs#L169-L220) | TLS 验证、最低权限、会话绑定、超时 |
| Rust → 文件 | [JSON 写入](../../src-tauri/src/queries.rs#L40-L109) | 单写者、原子替换、版本迁移、错误可见 |
| Rust → Agent | [本地服务与分析](../../src-tauri/src/lib.rs#L535-L625) | 认证、最小上下文、逐次外发授权、禁止隐式执行 |
| 打包 → 用户安装 | [安装替换](../../scripts/install.sh#L125-L149) | 签名验证、保留旧包、事务安全退出 |

## 2. 连接秘密与 Keychain｜P0

当前连接记录包含密码并直接写 JSON，AI 配置也含 API key，见 [连接模型](../../src-tauri/src/lib.rs#L114-L133)、[AI 保存](../../src-tauri/src/lib.rs#L454-L469)。
推荐 macOS 使用 Keychain；Windows 使用系统凭据保护，Linux 使用 Secret Service；统一 Rust SecretStore 接口。
凭据库不可用、被锁定或拒绝授权时，只允许用户选择“本次内存使用”，禁止自动回退明文。
公开配置仅含 secretRef 与 hasSecret；加载连接和 AI 配置不返回秘密原文给 WebView。
用户新输入秘密可在短生命周期表单中存在，保存后清空；不把状态 store、异常 Debug 或剪贴板当缓存。
Rust 秘密对象禁止默认 Debug/Serialize，减少克隆并在生命周期结束尽力清零；不承诺运行时所有副本可绝对擦除。
Keychain 服务名固定到应用，账户标识用连接 UUID + secret revision，不用可冲突的连接显示名。
证书私钥、SSH 私钥口令、AI key 与数据库密码分别授权；不要共用一个万能 secretRef。
连接导出继续排除所有秘密和内部凭据引用；用户名、主机也属于敏感元数据，可选匿名化导出。

### 秘密迁移顺序（后续实现时需用户明确同意）

1. 应用进入迁移只读态，锁住配置写入；检测 schemaVersion，不读取无关目录。
2. 仅对用户批准的旧连接配置读取旧结构；迁移日志不得含秘密、主机或原始 SQL。
3. 逐项写入 Keychain 新引用并验证可检索，迁移记录只保存 ID/状态；失败保留原状不继续清理。
4. 将不含秘密的 v2 配置写临时文件，校验、同步、原子替换；成功前不删除旧凭据的唯一可恢复来源。
5. 成功后清理旧结构中的秘密；若需备份，只能是脱敏备份或用凭据库管理密钥的加密备份。
6. 重启可按迁移 ID 幂等继续，失败不重复创建无限 Keychain 项，不把部分迁移误报全部完成。
7. Keychain 与文件不是一个事务：采用“先建秘密引用、再切配置、最后收孤儿”的补偿流程。
8. SSD、历史备份、同步盘可能残留旧明文；提示用户轮换相关秘密，不宣称文件覆盖等于物理擦除。

旧版应用不认识 v2 时不能读取新配置并回写成旧格式；回滚使用独立数据目录和脱敏导出重新导入。

## 3. TLS、证书与 SSH｜P1

Cargo 已启用 sqlx rustls，[配置证据](../../src-tauri/Cargo.toml#L22-L32) 不等于当前连接已强制验证证书。
推荐网络连接默认 verify-full：验证 CA 链、有效期和原始数据库主机名；握手失败必须可诊断。
自签 CA 由用户显式选择，保留指纹与来源；不使用“接受所有证书”消除连接错误。
生产连接禁止无声降级 TLS；本机隔离测试可显式选择无 TLS，界面持续显示风险，不继承到生产配置。
客户端证书与私钥有独立文件授权/凭据引用，私钥不导出、不放前端状态；证书到期给予预警。

SSH 隧道作为 S3 规划能力；当前未实现，不把普通主机连接宣传为已支持隧道。
推荐 Rust 内受管 SSH 适配器，不开放任意 shell 命令，也不将用户输入拼入进程命令行。
隧道只监听本机随机端口，绑定目标数据库地址，做主机密钥固定与首次指纹确认；变更必须重新批准。
隧道生命周期绑定 connection revision 与引用计数，断开后清理；隧道重建使数据库会话失效，不续接原事务。
SSH 只保护到跳板的路径；跳板到数据库仍应使用 TLS，不拿 SSH 替代数据库身份认证。
TLS 验证对象应是原始数据库主机，而不是 127.0.0.1 隧道端口；若驱动无法安全区分拨号目标和验证名则禁用组合。
具体 SSH 库与 sqlx TLS 主机名接入须经依赖审查和隔离握手验证后固定；不得用关闭证书校验作为兼容方案。

## 4. 危险 SQL、只读与授权｜P0

当前 [前缀分类](../../src-tauri/src/lib.rs#L232-L241) 仅分结果集路径，[通用执行](../../src-tauri/src/lib.rs#L757-L775) 没有安全审批。
推荐三层控制，任一失败均不得执行：数据库最低权限 → Rust 会话访问模式 → 后端审批与 SQL 风险分类。
只读账户在数据库端限制写入、DDL、危险函数与外部文件能力；客户端只读标签不能提升成数据库权限保证。
PG/MySQL 在适用事务中设置只读，仍需账户权限兜底；SQLite 以只读打开并禁止 ATTACH/扩展加载和危险 PRAGMA。
SQL 解析器用于识别语句/风险/目标，不是唯一安全边界；未知方言、动态 SQL、函数副作用不能用正则判断安全。
SELECT、WITH、EXPLAIN 都可能带副作用；EXPLAIN ANALYZE 会执行，不能因前缀“explain”免审。
只读连接不能通过 SET、注释包装、多语句、写入 CTE 或别名绕过；无法证明安全时拒绝只读通道。

| 风险 | 交互和后端规则 |
| --- | --- |
| 普通只读查询 | 用户主动执行；仍受权限、超时、结果量限制 |
| DML | 展示环境、目标与范围，授权固定 SQL/参数快照；生产默认显式事务 |
| 无条件 UPDATE/DELETE | 独立高风险确认，输入环境/对象确认语；不能一个常驻勾选永久放行 |
| DDL/TRUNCATE/权限变更 | 默认拒绝自动执行；人工单次授权；解释不可回滚语义 |
| 批量/导入 | 按整个批次计划审批，任一条改变使审批失效 |
| ANALYZE/维护/有副作用函数 | 独立管理风险类别；不伪装只读优化建议 |
| Agent 建议 | 仅草稿，永不自动执行破坏性 SQL；人工执行走同样的安全门禁 |

ApprovalGrant 拟定字段：approvalId、ownerWindow、sessionId、generation、connectionRevision、sqlDigest、parameterDigest、risk、expiresAt、consumed。
审批有效期初值 60 秒、单次使用；任何 SQL、参数、会话或环境变化都使其失效。
parameterDigest 使用带进程密钥的摘要，不用可枚举的裸密码/参数散列作日志；摘要本身也不外发。
由后端构建待审批摘要并触发原生确认路径，不能接受前端传 approved=true 直接放行。
渲染进程被攻陷仍可诱导交互，需结合原生目标展示与数据库最小权限；审批 token 不是对恶意宿主的万能隔离。

## 5. 事务、隔离级别与失败回滚｜P0 内核 / S3 写入

当前 [批量命令](../../src-tauri/src/lib.rs#L943-L968) 逐条重新分发，没有原子性；新事务必须依赖 [03 会话 actor](03_技术架构与性能优化.md)。
BEGIN、数据修改、COMMIT、ROLLBACK 必须由相同 session generation 的同一物理连接执行。
PG/MySQL 常规编辑推荐 READ COMMITTED，显式设置并展示实际隔离；只读一致快照按需用 REPEATABLE READ。
SQLite 不伪造 PG 隔离级别：采用短事务、写入前 BEGIN IMMEDIATE 和 busy timeout，实际锁语义单独展示。
MySQL 事务编辑仅面向事务型存储引擎；DDL 隐式提交、非事务表、外部副作用不能被“回滚”承诺覆盖。
网格编辑用唯一键和原值/版本的乐观条件；冲突返回原值变化，禁止盲目最后写入获胜。

| 故障点 | 必需状态与处理 |
| --- | --- |
| BEGIN 前失败 | failed，无数据库写入；可手动重试 |
| 事务内语句失败 | transaction=failed；默认整体 rollback，确认后才显示 rolledBack |
| PG 取消后事务 aborted | 禁止继续业务语句；原连接 rollback，再清理复位 |
| 连接中断且未提交 | 不重放；等待/核对数据库终态，无法确认则 unknown |
| COMMIT 已发出但响应丢失 | unknown，禁止自动重试 COMMIT 或重复 DML；提供核对指引 |
| 用户关闭标签 | 如有未提交变更先确认回滚；未结束前不回收该物理连接 |
| 导入分批已提交后失败 | 显示已提交批次和未提交批次；不声称整个文件已回滚 |

撤销编辑只撤销本地 change set；取消查询不等于回滚整个事务；回滚事务不撤销已经提交的事务。
数据库原生事务语句应纳入 actor 状态机；首期不支持的嵌套事务/存储过程直接声明限制，不让 UI 状态漂移。
重试只对明确未发送或只读且无副作用的请求经用户确认进行；写入不可按网络错误统一重试。

## 6. 持久化原子性、版本与历史脱敏｜P0 / P1

当前 [get_data_dir](../../src-tauri/src/queries.rs#L5-L16) 已支持目录覆盖，但创建目录错误被忽略；不得报成“缺少 DATA_DIR”。
推荐保留 JSON 作为轻量存储，避免本轮同时引入新的本地数据库迁移复杂度；先保证一致性再评估规模。
每类文件采用 schemaVersion、revision、updatedAt、payload、checksum 信封；checksum 只检错，不作为防篡改签名。
写入链路：校验 → 获取应用级单写锁 → 比较 revision → 同目录独占创建临时文件 → 写入 → sync → 原子替换 → 平台适配目录同步。
目录默认仅当前用户访问；拒绝未授权路径、符号链接替换和危险回退到工作目录，返回明确存储错误。
跨平台替换必须实现 Windows 文件占用与 rename 行为适配，不能假定 Unix 语义无条件成立。
同一应用第二实例使用文件锁，拿不到写锁则只读打开；进程内互斥不能防住跨进程丢更新。
异步命令中的阻塞文件 I/O 移到受限阻塞线程，不能把原子性实现成阻塞整个查询调度器。

迁移采用显式版本分支和可重放 journal；未知更高版本只读拒绝写入；不忽略未知字段后覆盖丢信息。
恢复优先使用最近一次已确认有效且脱敏的副本；发现损坏隔离文件，不能自动加载空数组再保存。
UI 启动区分未初始化、加载中、已加载、恢复错误；只有已加载状态才允许正常写入。

历史推荐记录 requestId、连接 ID/revision、schema、source、终态、SQL 模板、参数类型、耗时、行数和 safeErrorCode。
默认不记录参数值，不记录结果行；SQL 注释、连接串、字面量、错误文本都可能含秘密，需要词法脱敏和安全错误映射。
无法可靠脱敏的语句仅存摘要与失败原因码；不要为了历史可读性落盘未知原文。
收藏 SQL 也可能含秘密：保存前扫描提示并建议参数化；用户明确保存原文须了解本地保密风险。
生产连接可禁历史；清除历史同时清理备份/索引，但要说明系统备份和 SSD 残留不受应用绝对控制。
30 天/1000 条上限与 [02](02_产品能力与交互优化.md) 一致；清理按后端时钟和 revision 串行执行。

## 7. Agent 授权与出网边界｜P0

推荐 Agent 能力与 SQL 执行器解耦：Agent adapter 不接 DBConfig、不接连接租约、不暴露执行回调。
“分析已有结果”仅接受后端 resultId 和已批准样本引用，绝不为获取结果再次运行 SQL。
默认上下文仅为用户选中的必要 schema；发送真实样本必须逐次选择列、脱敏并批准最多 100 行/64 KiB。
表名、注释、查询结果中的自然语言一律是数据，不得提升为工具指令；生成 SQL 必须进入草稿复核。
新服务地址需用户授权，固定 scheme/host/port/path 策略；除明确配置的本地适配器外只允许 HTTPS。
禁任意跳转携带认证头；拒绝非 HTTP 协议、非预期内网探测与云元数据地址；DNS/重定向目标也需核验。
本地 Agent 使用握手身份与短期授权，端口被其他进程占用时拒绝发送；没有认证能力则保持不可用。
HTTP 默认 30 秒 deadline，响应大小上限 1 MiB；服务失败只报失败，不返回示例 SQL 冒充成功。
前端配置页仅显示凭据存在与服务能力；不回显 AI 秘密，不把供应商特定协议未经验证当通用协议。

## 8. Tauri 最小权限与发布安全｜P0 审核 / P1 加固

[默认 capability](../../src-tauri/capabilities/default.json#L1-L20) 含 fs、shell、dialog、clipboard；[CSP](../../src-tauri/tauri.conf.json#L22-L24) 为空。
推荐移除无业务证明的 shell 暴露；文件由用户选择句柄并在 Rust 校验，避免 WebView 持有宽泛文件权限。
权限名称不足以判断实际目录范围，需测试有效 capability scope；不可直接宣称现状“任意全盘读写”。
CSP 以本地打包资源为基础，不允许远程脚本和任意 eval；编辑器 worker 使用受控本地资源并验证兼容。
Rust HTTP 不受 WebView CSP 替代保护，必须单独做出网和凭据策略。
所有命令验证调用窗口与资源所有权；测试模拟伪造 sessionId、跨窗口 resultId、重放 approvalId 都应被拒绝。
数据库内容按文本渲染，不执行 HTML；Agent 输出和导入字段不使用不受控 HTML 注入。
构建发布分离测试与写仓库权限，签名/公证凭据仅在受保护发布阶段使用，不进入文档或日志。
安装先核验新包再请求应用结束事务并退出，保留旧签名包后原子替换；不默认强杀或清除系统隔离保护。

## 9. 安全验收与剩余风险

A06–A14、A21、A23、A24 为主要门禁；任何“未知提交状态被当成功”“秘密外发未授权”都阻断发布。
TLS、取消、只读和事务能力必须逐驱动、逐目标平台验证，不能用 SQLite 内存测试代替网络库安全验证。
暂未实现 Keychain、迁移、审批、CSP 收敛或 SSH；本次所有描述均为方案，不是已消除风险的证明。
规划新增：src-tauri/src/secrets.rs、src-tauri/src/ssh.rs、src-tauri/src/agent_service.rs；仅后续经授权实施时创建。
