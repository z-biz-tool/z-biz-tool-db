## 3. S1 可信内核（第 3–5 周）

### T-011 ConnectionManager 注册表 | R | 前置：T-007

- 规划新增 `src-tauri/src/db/mod.rs`、`src-tauri/src/db/pool.rs`。
- 实现连接池注册表：池键 = connectionId + revision + accessProfile。
- 复用现有 `mysql_pool`/`pg_pool`/`sqlite_pool` 作为工厂；全局最多 16 条活跃连接。
- 验收：A04 同一配置多次操作复用连接，不每次建池。

### T-012 Session Actor 与租约 | R | 前置：T-011

- 规划新增 `src-tauri/src/db/session.rs`。
- 每个 QuerySession 对应一个 actor（tokio task + mpsc channel），独占一条物理连接。
- 事务内所有 SQL 在同一 actor 执行，不跨连接。
- 验收：A05 BEGIN → DML → COMMIT 在同一物理连接上，连接中断后不继续。

### T-013 查询取消协议 | R | 前置：T-012

- `src-tauri/src/db/session.rs` 新增 cancel_requested 信号。
- PG：控制连接调用 `pg_cancel_backend(pid)`；MySQL：`KILL QUERY connectionId`；SQLite：评估 interrupt API。
- 取消 ≠ kill connection；2 秒未确认转 pending → unknown 并隔离租约。
- 验收：A05 取消后连接不泄漏、事务状态准确。

### T-014 Keychain 实现（macOS） | R+S | 前置：T-007

- 完善 `src-tauri/src/secrets.rs`：macOS 使用 security-framework crate；Windows/Linux stub 返回不可用。
- 秘密保存/读取/删除通过 SecretStore trait；应用不缓存明文超过操作生命周期。
- 验收：A10 Keychain 读写可逆，拒绝访问时降级为仅内存。

### T-015 秘密迁移流程 | R+S | 前置：T-014

- 启动时检测旧配置含明文密码，提示用户授权迁移。
- 逐项写入 Keychain → 验证可检索 → 原子更新配置（不含密码）→ 清理旧明文。
- 失败中断保留原状，不半迁移。
- 验收：A11 迁移前后连接可用，旧文件不再含明文秘密。

### T-016 持久化版本化与恢复 | R | 前置：T-008

- `src-tauri/src/queries.rs` 所有文件加入信封结构：`{schemaVersion, revision, updatedAt, payload, checksum}`。
- 加载失败进入恢复态：隔离损坏文件 → 尝试备份 → UI 展示恢复选项。
- 验收：A12 损坏文件不导致静默清空后覆盖。

### T-017 历史/收藏后端持久化接通 | R+F | 前置：T-016

- 验收：A12 重启后历史和收藏保持。

### T-018 请求去重与 ID 生成 | R | 前置：T-012
