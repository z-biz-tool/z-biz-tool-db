# 产品能力与交互优化

> 设计方案，未实现；基线 dc18deb7eae6267abd8ccc5e7453c05e89ad1644；事实=静态代码证据，目标=拟定验收。
> 下述流程是推荐目标；当前缺口编号与证据统一见 [01 审计](01_现状审计与问题清单.md)。

## 1. 用户任务与工作台结构

主任务：选择可信连接 → 确认环境/schema → 编写并审阅 SQL → 执行/取消 → 检查结果 → 按需编辑提交或导出 → 保存可复用查询 → 安全退出。
不要把“已连接”绿色标签等同于长期数据库会话存在；当前 [连接流程](../../src/App.tsx#L458-L535) 只是一次测试成功后更新 UI。
工作台维持三栏，但连接导航与 schema 导航合为可折叠左栏，中间给编辑器和结果，右侧历史/Agent 默认收起。
在最小窗口宽度下优先保留 SQL 与结果，不让三个固定宽度侧栏挤掉实际工作区域。
顶栏始终显示连接名称、环境文字、数据库、schema、只读/可写、事务状态和连接健康状态。

| 角色 | 高频任务 | 默认防护 |
| --- | --- | --- |
| 开发者 | 多环境切换、参数查询、定位结构、调试脚本 | 新连接只读，标签绑定环境 |
| 数据分析人员 | 大结果筛选、比较、导出、复用 SQL | 结果分批读取，脱敏导出提示 |
| 授权运维人员 | 故障排查、受控修数、查看计划 | 高危确认、事务面板、未知提交状态处理 |

## 2. 多连接与环境标记｜P0 身份 / P1 易用性

当前：保存多连接列表，但只有一份全局选中连接；编辑连接后原选中对象未建立修订同步，见 DB-10、DB-11。
推荐：连接配置与连接会话分离，同一配置可创建多个互相隔离的标签会话。
环境是 dev/test/staging/prod/custom 枚举，默认 unknown；导入和旧配置不根据主机名称猜成开发环境。
颜色只作辅助，必须显示“生产”“测试”“未知”等文字；生产环境顶栏、标签、确认框同步标记。
连接列表支持分组、搜索、最近使用；不默认自动连接所有已保存配置。
删除连接前列出关联标签、查询和事务；执行中的连接不能静默删除，先走关闭流程。
配置修订后新会话使用新 revision，旧会话标记“配置已变更，需重连”，不在事务中热替换凭据。

### 新建连接向导

1. 选 MySQL/PostgreSQL/SQLite；SQL Server 暂不可用并说明，不让用户填写后才失败。
2. 网络库填主机、端口、数据库与账户；SQLite 改为文件选择，隐藏无意义的必填用户名。
3. 检测主机中附带端口，展示解析结果；与独立端口冲突时要求确认，不静默覆盖。
4. 配置 TLS 身份验证；生产网络连接不能静默降级明文，详见 [04 安全](04_数据安全与可靠性.md)。
5. 测试连接只做短时探测，显示耗时与错误分类；不拉全表数据、不更改 schema。
6. 选择是否保存秘密；默认凭据库，拒绝访问时可仅本次内存使用。
7. 保存完成才提示成功；失败保持草稿与重试入口，不伪造“连接已创建”。

## 3. schema 导航｜P0 精确定位 / P1 完整浏览

当前 [表树](../../src/App.tsx#L847-L879) 使用表名作为 key，无法区分 PG 多 schema 同名表，见 DB-12。
推荐树层次为连接 → catalog/database → schema → 表/视图 → 列/索引/外键。
MySQL 将 database 映射到 schema 层但显示原生语义；SQLite 首期只显示已打开的 main，不自动 ATTACH 任意文件。
每个节点用结构化对象引用，展示完整限定名；名称搜索不触发 SQL 执行。
节点懒加载、显式刷新，展示缓存时间；执行 DDL 后失效对应对象缓存，不全库无限刷新。
行数展示“估算”或“未知”，不能把 null 转成 0；大小注明统计口径，不用于账务核验。
双击表默认打开只读数据页，采用稳定主键顺序；没有唯一键时明确分页不稳定且禁止网格编辑。
列页显示类型、可空、默认值、主键；P2 再补索引、外键、注释和依赖关系，不先做复杂 ER 画布。
复制对象名时按当前方言引用，不使用简单拼接或用户输入作为 SQL 标识符。

## 4. SQL 编辑器｜P0 语义保护 / P1 专业操作

当前主编辑器是 [TextArea](../../src/App.tsx#L903-L921)，另一个组件并未集成；格式化为正则替换，见 DB-13。
推荐采用 CodeMirror 6 作为唯一编辑器内核；首期保留 Ant Design 外框，避免同时维护两套编辑器。
编辑状态直接归属标签，输入即更新草稿；切换、新建、关闭标签都不能遗漏同步。
明确三个动作：“执行选中内容”“执行当前语句”“运行脚本”，默认执行当前语句而非整个文件。
语句边界必须识别字符串、注释和方言块，不能直接按分号 split；无法解析时只允许用户显式选择内容。
执行前固定 SQL 快照、参数、连接 revision、schema 与授权；执行中继续编辑不影响正在运行的快照。
支持行号、语法高亮、查找替换、注释、括号匹配、schema 补全；补全只读取获准元数据。
参数面板区分数据值和标识符；值走驱动绑定，表名/排序方向不作为普通参数字符串拼接。
格式化展示可撤销变更；字符串、注释、大小写敏感标识符不被修改，错误时保持原文。
建议快捷键：Cmd/Ctrl+Enter 当前语句、Shift+Cmd/Ctrl+Enter 明确运行脚本；首次脚本运行显示说明。
快捷键与按钮进入同一授权路径，不能绕过只读模式与危险 SQL 确认。

## 5. 查询生命周期与结果展示｜P0 正确性 / P1 大规模

当前 [查询 UI](../../src/App.tsx#L192-L247) 没有作业身份、取消、排队或重复执行保护。
每标签默认只有一个活动查询；重复点击返回同一 requestId 状态，不额外提交 SQL。
状态顺序：排队 → 连接准备 → 执行中 → 接收批次 → 完成；可转取消请求、失败或状态未知。
“停止”立即变为“正在请求取消”；收到停止确认且连接清理完成才显示“已取消”。
如果无法确认数据库是否停止，显示“状态未知，连接已隔离”，不把关闭前端 Promise 当完成。
结果头部显示查询快照、连接/schema、读取行数、截断/分页状态、服务端耗时和客户端总耗时。

| 场景 | 目标展示与操作 |
| --- | --- |
| 零行 SELECT | 仍显示列名与类型，提示 0 行，而不是空白无结构 |
| DML 完成 | 独立显示影响行数与提交状态，不把无结果集当查询失败 |
| 同名列 | 按 ordinal 区分，标题可相同；复制表头标明列序，不覆盖数据 |
| SQL NULL | 专用 NULL 标识；空字符串、文本 null、JSON null 均不同 |
| 大整数/Decimal | 原文字符串展示与复制，禁止先转 Number；客户端局部排序必须标范围 |
| 二进制 | 长度、hex/base64 预览；全文按授权下载，不使用有损字符替代 |
| 日期时间 | 标明时区/无时区；可切显示时区但保留原值与查询会话时区 |
| 大单元格 | 默认截断显示，显式展开受长度上限控制；不把显示截断当数据截断 |
| 解码失败 | 单元格警示及类型，不显示为 NULL；可导出结构化错误报告 |
| 结果未取完 | 明确“已读取 N 行，尚未完成”；总行数未知，不自动做昂贵 COUNT |

普通页大小默认 200，结果批次上限 500 行且 1 MiB；参数为拟定值，详见 [03 内核](03_技术架构与性能优化.md)。
结果采用虚拟滚动与有界缓存，不因为用户只看第 1 页而在后台悄悄拉满 10 万行。
自由 SQL 的“继续读取”消费同一次执行的流；表浏览“下一页”使用服务端 keyset，二者文案区分。
排序/过滤选择“当前已加载结果”或“重新查询数据库”；后者必须展示重执行提示和新结果版本。

## 6. 编辑、事务与修数｜P1 内核后置 / S3 上线

当前没有网格编辑或提交面板，不能把已有 execute_batch 当可用事务接口，见 DB-07、DB-24。
推荐只允许可确定来源的单表、唯一键可用、类型可绑定的结果编辑；JOIN、表达式列和无键表只读。
双击单元格进入本地编辑，变更进入 change set，不立即写库；NULL 使用独立动作，不能用空输入替代。
“预览变更”列出目标完整表名、原值、目标值、主键与预计影响范围；值参数化，不把明文敏感值写日志。
“应用到事务”在固定会话物理连接上 BEGIN，并做乐观并发条件校验；0 行为冲突，多于 1 行为安全失败。
事务条显示 active/failed/提交中/已提交/已回滚/unknown；自动提交与显式事务不得混淆。
提交前再次确认生产环境与变更数量；提交后刷新受影响对象，不能继续编辑过期快照。
用户取消、关闭标签或退出应用时提供“回滚并关闭”“返回处理”；不默认提交未提交变更。
数据库断线后不自动重放写入；COMMIT 响应丢失显示状态未知，转人工核对。
MySQL 非事务表或隐式提交 DDL 不纳入“可回滚编辑”；首期明确拒绝该模式。

## 7. 历史、收藏与恢复｜P1

当前历史/收藏主 UI 是内存状态且含样例数据，后端存取命令未接通，见 DB-15。
历史由 Rust 在作业终态统一记录，包含连接 revision、schema、来源、状态、耗时、影响行数和脱敏 SQL。
失败和取消同样记录；前端重试或事件重放按 requestId 去重，不重复添加成功记录。
默认持久化模板与占位符，不存参数值；敏感会话允许完全关闭历史。
建议保留 30 天且最多 1000 条，先到者生效；这是产品初值，不是现状。
“复用历史”只打开草稿，不自动执行；原连接不存在或 revision 改变时要求重新绑定环境。
收藏支持名称、说明、标签、方言、参数定义和适用环境；保存成功必须以持久化确认为准。
草稿恢复只恢复 SQL 和布局，不恢复活动事务、活动查询或授权 token。

## 8. 导入与导出｜P1 输出 / S3 写入

当前连接导出已排除密码；连接导入缺 UI，结果导出按钮无动作，见 DB-16。
连接配置交换：导入先校验版本、驱动、端口、大小和条数，再预览新增/冲突；不携带秘密、不导入后自动连接。
结果导出：选择 CSV 或类型保真的 JSONL、字符编码、NULL 表示、列范围及脱敏规则。
当前缓存导出只能声明“已加载结果”；完整导出必须显式新建只读导出作业，不伪称沿用已释放的快照。
完整导出以 Rust 流式写入用户选定文件，显示行数/字节/取消；写完同步后原子完成，失败保留可识别的部分文件。
CSV 提供表格公式防护模式；JSONL 保留整数和二进制标签；格式语义不能只靠文件扩展名猜测。
数据导入首期仅 CSV → 既有单表，不自动建库/改 schema；提供编码、列映射、类型预检和首批预览。
导入使用绑定参数与有界批次；默认整单事务设置大小限制，超限要求显式分批提交并说明不可整体回滚。
导入重试仅重试未提交批次；未知提交状态暂停并人工核对，不能重复插入。

## 9. 执行计划与诊断｜P2，基础只读计划可在 S2

当前可手写 EXPLAIN，但没有专用面板；前缀分支不等于完整计划能力，见 DB-06、DB-24。
推荐先支持 MySQL EXPLAIN、PG EXPLAIN JSON、SQLite EXPLAIN QUERY PLAN 的驱动映射与原始输出。
先看估算计划，不自动加 ANALYZE；带执行行为的分析必须走独立授权且告知实际运行与副作用。
计划保留 SQL 快照、参数类型、引擎版本、schema 版本与时间；不同条件的计划不直接比较耗时优劣。
热点提示区分估算行数偏差、扫描方式、排序/临时空间与缺失统计；索引建议仅生成草稿。
不以“优化 SQL”按钮承诺更快，不自动执行 CREATE INDEX、ANALYZE 或维护命令。

## 10. Agent 辅助｜P0 禁隐式执行 / P1–P2 真正接入

当前有三套不一致路径，主 UI 的 store 是示例；Rust 分析命令有重执行风险，见 DB-04、DB-05。
推荐统一“生成、解释、优化、诊断、分析已有结果”意图，不靠中文关键词猜测可执行权限。
首次使用展示服务来源与数据发送范围；默认只给必要 schema，不自动发送样本记录。
分析结果选择 resultId、列与最多 100 行/64 KiB 脱敏样本，逐次确认，取消后不得继续外发。
建议以 diff 展示，按钮只有“复制”“插入新草稿”“替换选区”；没有“生成后自动执行”。
用户手动执行建议仍使用常规查询授权；破坏性 SQL 不得由 Agent 自动执行，即使用户已允许对话。
服务不可达、配置无效、上下文过期都显示真实原因；严禁回落为固定 users SQL 并标成功。
本地服务同样需要身份认证；“在 localhost”不是数据授权，服务未开启时不主动启动它。

## 11. 空态、错误态与体验验收

空库、无权限、加载失败和未连接必须是四个不同状态，不统一显示“暂无数据”。
错误包含 requestId、阶段、可重试性与安全摘要；复制诊断信息默认去 SQL 字面量、主机和账户。
连接测试失败保留表单；存储失败保留草稿；取消失败保留查询状态；不可逆操作没有通用自动重试。
无障碍要求：焦点可达、确认框默认焦点在取消、环境信息不用颜色独占、键盘可完成连接到导出流程。
流程验收覆盖 A04、A15–A22；只有 [06](06_测试验收与风险清单.md) 中相应门禁实际通过后才可描述为已交付。
